## 7. Top 5 Fixes

Ordered by impact vs. effort:

### Fix 1: Eliminate dual lockfile drift & configure Dependabot for pnpm
- **Problem:** `package-lock.json` and `pnpm-lock.yaml` both exist. Dependabot generates PRs updating `package-lock.json`, while CI strictly runs `pnpm`.
- **Evidence:** Commit `1a5a69c` by Dependabot touched `package-lock.json`; `.github/workflows/deploy.yml` uses `pnpm`.
- **Proposed Change:** Delete `package-lock.json`, add `.github/dependabot.yml` specifying `package-ecosystem: "npm"` with `package-manager: "pnpm"` (or ignore npm lockfile in git).
- **Effort:** S
- **Verification Command:** `git rm package-lock.json && pnpm install --frozen-lockfile`

### Fix 2: Resolve TypeScript index signature errors in `tests/i18n.test.ts`
- **Problem:** `pnpm exec tsc --noEmit` fails with 6 type errors when accessing dictionary records dynamically.
- **Evidence:** `tests/i18n.test.ts:27,28,39,40,70,71` reports `Element implicitly has an 'any' type`.
- **Proposed Change:** Add index signature or cast key lookup (`(dict.nav as Record<string, string>)[key]`).
- **Effort:** S
- **Verification Command:** `pnpm exec astro sync && pnpm exec tsc --noEmit`

### Fix 3: Upgrade Astro and patch transitive vulnerabilities (`undici`, `devalue`)
- **Problem:** `pnpm audit` reports 21 vulnerabilities (9 high, 8 moderate, 4 low), mostly in transitive `undici` and `devalue`.
- **Evidence:** `pnpm audit --audit-level=high` outputs 9 high vulnerabilities; `astro` is on 7.2.10 while 7.3.8 is available.
- **Proposed Change:** Update `astro`, `@astrojs/mdx`, and `@astrojs/svelte` to latest patch/minor versions.
- **Effort:** S
- **Verification Command:** `pnpm update astro @astrojs/mdx @astrojs/svelte && pnpm audit --audit-level=high`

### Fix 4: Secure `blog-sync.yml` automation against shell injection
- **Problem:** Issue title and body are directly concatenated into a bash script and committed directly to `main`.
- **Evidence:** `.github/workflows/blog-sync.yml:34-45` uses raw environment variable substitution in `cat > ... << 'ENDOFFRONTMATTER'`.
- **Proposed Change:** Replace inline bash string manipulation with a Node.js script using `fs.writeFileSync`, validate slug sanitation, and dispatch changes via Pull Request rather than direct push to `main`.
- **Effort:** M
- **Verification Command:** `node scripts/validate-blog-sync.mjs`

### Fix 5: Clean internal artifacts, add `AGENTS.md`, and complete `README.md`
- **Problem:** 14+ internal development files (`.hermes/`, `.gitcore/`, `docs/SWAL/`) exist in public repo; `AGENTS.md` is missing; `README.md` omits Svelte and test scripts; `package.json` lacks `"license"`.
- **Evidence:** `ls AGENTS.md` fails; `find .gitcore .hermes docs/SWAL` returns 14 tracked internal files.
- **Proposed Change:** Remove internal planning files from git tracking or add to `.gitignore`; create `AGENTS.md` documenting build/test/audit gates; update `README.md` and `package.json`.
- **Effort:** M
- **Verification Command:** `test -f AGENTS.md && test -z "$(git status -s)"`
